Complete Technical Architecture & Folder Dependency Mapping

Database & ORM

PostgreSQL & Prisma 6

Styling

Tailwind CSS v4 & Framer Motion

Authentication

Jose (JWT) & Edge Middleware

📂 Major Folders Overview

prisma/ Database Layer

Manages the relational database schema, database modeling, and migration history for PostgreSQL.

  • schema.prisma: Defines 14 database models (User, Landlord, Property, Tenant, Lease, RentPayment, Contractor, Maintenance, RatesAndLevy, RatesAndLevyEntry, MoveRecord, PropertyDocument, Client, MaintenanceContact) and 8 domain Enums.
  • migrations/: SQL scripts tracking database schema changes.
Depends On

PostgreSQL Database, @prisma/client package.

Depended On By

src/lib/prisma.ts, all backend API routes (src/app/api/) & Server Actions.

src/app/ Pages, APIs & Server Actions

Root of the Next.js App Router containing page components, RESTful API endpoints, server actions, and layout declarations.

  • (agent)/: Authenticated agent portal containing dashboard, properties, clients, maintenance, payments views and shared layout.tsx.
  • actions/ (auth.ts): Server actions for user login, signup, password hashing (bcryptjs), and JWT session creation.
  • api/: 15 RESTful API routes providing backend CRUD endpoints for all application domain entities.
  • register/ & page.tsx: User registration page and login/landing page.
  • globals.css & layout.tsx: Global Tailwind styles and top-level HTML root wrapper.
Depends On

src/components/, src/lib/, src/schemas/, src/types/, Lucide icons, Framer Motion.

Depended On By

End-user web browser requests and external API callers.

src/components/ UI Components Layer

Contains modular React frontend UI components grouped by feature responsibility.

  • agent/: Agent widgets and forms (AgentHeader, AgentSidebar, KpiCard, RentChart, UrgentTickets, PropertyForm, ClientForm, MaintenanceForm, ThemeProvider, ThemeToggle).
  • shared/: Cross-cutting components (Header, StatusBadge, EmptyState, MobileBottomNav).
  • auth/ & ui/: Directory hooks for authentication views and base UI primitives.
Depends On

lucide-react, framer-motion, react-hook-form, src/types/, src/schemas/, src/lib/utils.ts.

Depended On By

Page views inside src/app/.

src/lib/ Core Utilities & Singletons

Utility modules, singletons, session encryption, and class name merging logic.

  • prisma.ts: Global singleton instance of PrismaClient.
  • session.ts: JWT creation, cookie encryption/decryption, and session verification using jose.
  • utils.ts: Class helper cn() joining Tailwind classes via clsx and tailwind-merge.
  • validation.ts & constants.ts: Input validation utilities and system constants.
Depends On

@prisma/client, jose, clsx, tailwind-merge.

Depended On By

API routes in src/app/api/, Server Actions, Middleware, and UI Components.

src/schemas/ Zod Schema Validation

Runtime schema definitions ensuring strict data validation for forms and API requests.

  • property.ts: Zod schema validating property fields (code, name, address, property type, status, landlord ID).
Depends On

zod package.

Depended On By

PropertyForm.tsx (Client validation) & /api/property/route.ts (Server validation).

src/types/ TypeScript Types

Central repository for shared TypeScript interfaces and domain object type definitions.

  • property.ts: Type interfaces for Property, PropertyFormData, Tenant, Lease, Landlord, Maintenance.
Depends On

Standard TypeScript.

Depended On By

React components (src/components/), agent pages (src/app/(agent)/), API routes (src/app/api/).

src/middleware.ts Edge Security Middleware

Next.js Edge Middleware intercepting HTTP requests for route authentication and session validation.

Depends On

next/server, jose (jwtVerify).

Depended On By

Every incoming HTTP request lifecycle.

public/ Static Assets

Public static assets served directly at domain root (favicons, logos, static images).

Depends On

None.

Depended On By

Next.js layout (src/app/layout.tsx) and HTML <img> tags.
